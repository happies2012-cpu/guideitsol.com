# 90-Day Marketing Blueprint

## Month 1: Foundation & Fixes (Technical & SEO)
**Goal**: Prepare the site for traffic.

- **Week 1**:
  - [x] Fix broken links in Header/Footer.
  - [x] Implement "Lead Magnet Popup".
  - [x] Update Meta Tags for top 20 pages.
- **Week 2**:
  - [x] Set up Google Search Console & Analytics.
  - [x] Submit new `sitemap.xml`.
  - [x] Speed optimization (Compress images).
- **Week 3**:
  - [ ] Write 4 foundational Blog Posts (Pillar content).
  - [ ] Create LinkedIn Company Page & optimize profile.
- **Week 4**:
  - [ ] Launch "Travel Portal Checklist" Lead Magnet.
  - [ ] Set up Email Marketing software (Mailchimp/ConvertKit).

## Month 2: Content Engine & Outbound (Traffic)
**Goal**: Drive first 1,000 targeted visitors.

- **Week 5**:
  - [ ] Publish 2 Blog Posts/week.
  - [ ] Start LinkedIn posting (3x/week).
- **Week 6**:
  - [ ] Launch "Cold Email Campaign" targeting Travel Agencies.
  - [ ] Guest post outreach (Pitch 10 blogs).
- **Week 7**:
  - [ ] Create Case Study PDF for Sales Team.
  - [ ] Start small PPC test ($10/day on Google Ads).
- **Week 8**:
  - [ ] Analyze traffic data; optimize high-bounce pages.
  - [ ] Webinar: "How to Build a Travel App in 2025".

## Month 3: Scaling & Automation (Leads)
**Goal**: Generate 50 qualified leads.

- **Week 9**:
  - [ ] Launch "Retargeting Ads" (Facebook/LinkedIn).
  - [ ] Automate social media scheduling.
- **Week 10**:
  - [ ] Create 2nd Lead Magnet (e.g., "Offshore Hiring Guide").
  - [ ] A/B Test Landing Page headlines.
- **Week 11**:
  - [ ] Partner with a complementary agency (Referral swap).
  - [ ] Publish "Ultimate Guide" (3,000 words) for SEO.
- **Week 12**:
  - [ ] Quarterly Review: ROI calculation.
  - [ ] Plan Q2 Strategy based on data.
