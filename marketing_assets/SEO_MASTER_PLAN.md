# SEO Master Plan for GuideIT Solutions

## 1. Technical SEO Audit & Fixes
- [x] **Robots.txt**: Validated. Points to sitemap.
- [ ] **Sitemap.xml**: Needs update to include all ~100 pages found in codebase.
- [ ] **Canonical Tags**: Ensure every page has a self-referencing canonical tag.
- [ ] **Schema Markup**: Add specific schema for "SoftwareApplication", "Service", and "BreadcrumbList".
- [ ] **Page Speed**: Optimize images in `public/` and enable lazy loading (already partially implemented in React).

## 2. Keyword Strategy
**Primary Keywords**:
- IT Solutions Company
- Custom Software Development
- Hire Dedicated Developers
- Travel Technology Solutions
- AI Business Integration

**Long-tail Strategy**:
- "Hire ReactJS Developers in India"
- "Flight Booking Engine API Integration"
- "Custom B2B Travel Portal Development"

## 3. On-Page Optimization Plan
For each of the 100+ pages:
- **Title Tag**: `[Service Name] | GuideIT Solutions` (Unique for every page)
- **Meta Description**: Action-oriented, under 160 chars.
- **H1 Tag**: Must match the primary keyword.
- **Internal Linking**: Link related services (e.g., "Web Development" -> "Hire React Developers").

## 4. Content Gaps
- **Blog**: The `/blog` section needs regular high-quality content.
- **Case Studies**: `/company/case-studies` should have detailed success stories.
- **Glossary**: `/company/glossary` is a great SEO asset; needs 50+ terms.

## 5. Execution Roadmap
1. **Immediate**: Update `sitemap.xml` with all discovered routes.
2. **Short-term**: Generate unique meta tags for top 20 pages.
3. **Mid-term**: create content for "Glossary" and "Case Studies".
